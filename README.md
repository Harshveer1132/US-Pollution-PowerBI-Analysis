# U.S. Pollution Analysis | Power BI

## Project Overview

This project analyzes U.S. pollution data using Power BI. The analysis focuses on four major pollutants: Carbon Monoxide (CO), Ozone (O3), Sulphur Dioxide (SO2), and Nitrogen Dioxide (NO2).

## Tools Used

* Microsoft Excel – Data Cleaning
* Power BI – Data Analysis and Visualization

## Key Analysis

* State and city-wise pollution analysis
* Year-wise and quarter-wise comparisons
* AQI analysis of major pollutants
* Interactive slicers and dashboard navigation

## Dashboard Preview

The Power BI report includes an Overview page and separate pages for each pollutant.
